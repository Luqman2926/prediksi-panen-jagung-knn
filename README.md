# Corn Yield Prediction System (KNN + Flask)

Repository ini berisi kode sumber dan dataset untuk penelitian "Implementation of the K-Nearest Neighbors Method in a Web-Based Corn Yield Prediction System".

## Struktur File
- `model/data_jagung.csv`: Dataset sekunder & primer panen jagung Sleman.
- `app.py`: Aplikasi web utama berbasis Flask.
- `requirements.txt`: Daftar pustaka Python yang dibutuhkan.

## Cara Menjalankan
1. Clone repository: `git clone https://github.com/username/prediksi-panen-jagung-knn-flask.git`
2. Install dependensi: `pip install -r requirements.txt`
3. Jalankan aplikasi: `python app.py`
